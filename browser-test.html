Browser tests

Many browser features require a browser context to operate. You may not want to set up selenium / playwrite for your project. Instead use this simple html page which includes a very simple test harness for automated tests.

For these tests to work, a fileserver must be run in the root of this project. Try, for example: caddy file-server --location :8080.

If no test results appear, or one or more sections is missing results, check the console for errors or logs.
